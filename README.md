# INNO-MAC JHB Website

This is a simple multi-page website for INNO-MAC JHB, an independent Land Rover, Range Rover and Jaguar specialist workshop.

## Pages

- `part 2/Website/index.html` - Home page
- `part 2/Website/About.html` - About the workshop
- `part 2/Website/Services.html` - Services and vehicles
- `part 2/Website/Enquiry.html` - Enquiry form
- `part 2/Website/Contact Us.html` - Contact details
- `part 2/Website/sitemap.html` - Site map
- `CHANGELOG.md` - Project changes by version
- `wireframes.md` - Basic website page wireframes

## How to view the website

Open `part 2/Website/index.html` in a web browser. The website uses the images in the `assets/images` folder and the shared `styles.css` file.

## Technologies used

- HTML5
- CSS3

No JavaScript or advanced frameworks are used. The layout adjusts for smaller screens with simple CSS media queries.

## Project notes

The enquiry form is currently a front-end form. A server or form service would be needed to receive submitted enquiries.
